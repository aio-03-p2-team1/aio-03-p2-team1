## 전단지 기능 및 실종 신고 게시판

전단지 기능을 직접 시연하거나 영상으로 보여준다.

포함 사항:
- 전단지 작성 및 게시글 업로드

시연 흐름:
1. 전단지 템플릿을 보여준다.
2. 긴급형 템플릿에 직접 사진과 정보를 입력한다.
3. PNG 파일로 다운로드한다.
4. 다운로드한 PNG 파일로 직접 게시글을 업로드한다.
5. 업로드한 전단지로 직접 Try Search를 실행한다.
