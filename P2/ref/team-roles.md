# Team 다시마 역할 분담

| 팀원 | 주요 기여 |
| --- | --- |
| 변건형 | 서버 셋업 및 배포, 프로젝트 기반을 구축하고, 검색 에이전트의 결과 검토·재조회를 개선했다. 실제 API와 LLM으로 검색 동작을 검증했다. |

| 이희래 | 화면 디자인, 실종 게시글의 정보와 사진을 구조 공고 검색에 연결하고, 검색 에이전트 루프와 거리 순위를 구현했다. |
