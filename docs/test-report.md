## 3. 성찰 전후 비교 (필수 지표)

비교 조건: 같은 시나리오·모델·정렬 기준, `reflection_enabled` 만 바꾼다(`POST /searches` 의 `reflection_enabled`).

| 지표 | 산정 기준 | 성찰 전 | 성찰 후 |
| --- | --- | --- | --- |
| 태스크 완료율 | 시나리오 완료 조건 만족 건수 / 전체 시험 건수 | 미측정 | 미측정 |
| 도구 선택 정확도 | 허용 도구 조합과 일치한 건수 / 전체 판정 건수 | 미측정 | 미측정 |
| 응답 일관성 점수 | 같은 입력 반복 시 사실·조건·구조 일치 비율 | 미측정 | 미측정 |
| 평균 재시행 횟수 | `reflection_count` 평균(통신 재시도 `retry_count` 는 별도) | 미측정 | 미측정 |
