### v0.2 검증

- 외부 API/임베딩은 FakeAnimal·FakeEmbedder 또는 httpx.MockTransport, Redis는 fakeredis로 시험한다. 실제 OpenAI 호출·검색 품질·운영 응답 시간·비용은 미측정이다.
- 1,000건 조회/전체 임베딩, RRF 합산, 300건 제한/TTL, 재검색·동시 캐시 미스 중복 방지, 만료 재조회, 임베딩 실패 비캐시, 페이지/상세 소유자 격리, 이전 스냅샷 보존, Redis 장애 시 외부 호출 차단, 기억/명시 입력의 동일 조건 캐시 재사용과 출처 보존을 검증한다.
- 프론트는 URL 페이지 검증·캐시 만료/보관 상한 단위 시험과 production 빌드를 수행한다. 실제 브라우저 뒤로가기·스크롤 복원은 수동 확인이 필요하다.
